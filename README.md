# Cardputer-Studio
Cardputer Studio把三个开源音乐固件去重整合、统一界面，做成了 M5Stack上的一套完整音乐系统：一台 18 种波形的可演奏合成器、一台网络收音机，还有一个能用麦克风听出歌曲调性与节拍的「耳朵」。  Cardputer Studio unifies three open-source Cardputer music firmwares into one polished system: a playable 18-waveform synthesizer, an internet radio, and a microphone that hears a song's key and tempo — all on the M5Stack Cardputer ADV.
