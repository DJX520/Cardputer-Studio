# Cardputer Studio — 烧录与使用教程（详细版）

本教程带你从零开始，把 `CardputerStudio` 烧录进 **M5Stack Cardputer ADV**，并学会操作三个模式。

---

## 第 0 步：准备

- M5Stack Cardputer ADV 一台
- USB-C 数据线
- 已安装 **Arduino IDE 2.x**（或 1.8.x）
- （可选）一张 microSD 卡（放电台表 / 音色库）

---

## 第 1 步：装板包

1. 打开 Arduino IDE → **文件(File) → 首选项(Preferences)**。
2. 在「附加开发板管理器网址」里添加一行：
   ```
   https://m5stack.oss-cn-shenzhen.aliyuncs.com/resource/arduino/package_m5stack_index.json
   ```
   如果已有其他地址，点右侧图标换行再粘贴。
3. **工具(Tools) → 开发板(Board) → 开发板管理器(Boards Manager)**，搜索 `M5Stack`，安装 **M5Stack by M5Stack**。

## 第 2 步：装依赖库

**工具 → 管理库(Library Manager)**，依次搜索并安装：

| 搜索关键词 | 装哪个 |
|---|---|
| `M5Unified` | M5Unified（M5Stack） |
| `M5Cardputer` | （可选）键盘已自包含，可不装 |
| `M5GFX` | M5GFX（M5Stack） |
| `ESP32-audioI2S` | ESP32-audioI2S（schreibfaul1） |

> 装 M5Unified / M5Cardputer 时会自动带上 M5GFX。

## 第 3 步：打开工程

1. 把整个 `CardputerStudio` 文件夹复制到你电脑上（例如 `D:\CardputerStudio`）。
2. Arduino IDE → 文件 → 打开 → 选择 `CardputerStudio.ino`。
3. 打开后，左侧会看到所有 `.h` / `.cpp` / `.ino` 分页。

## 第 4 步：选板与分区（关键）

1. **工具 → 开发板** → 选 **M5Stack Cardputer**。
2. **工具 → Partition Scheme** → 选 **Huge APP (3MB No OTA / 1MB SPIFFS)**。
   - 收音机 + 合成器二进制较大，**必须用这个分区**，否则编译会提示 Flash 超限。
3. **工具 → Flash Size** → **8MB (64Mb)**。
4. **工具 → PSRAM** → **Disabled**（本机无 PSRAM）。
5. （建议）**工具 → USB CDC On Boot** → **Enabled**，便于看串口日志。

## 第 5 步：编译并烧录

1. 用 USB-C 连上 Cardputer。
2. **工具 → 端口** 选对应串口（如 `COM3`）。
3. 点 **上传(→)** 按钮（或 Ctrl+U）。
4. 等编译（首次约几分钟）完成后自动写入。屏幕显示 **CARD STUDIO** 启动器即成功。

> 若卡在「Connecting…」，按住 Cardputer 侧边 **G0** 键再按一下 **RST**，然后松开，进入下载模式后重试。

## 第 6 步：可选 —— SD 卡电台表

1. 把 `station_list.txt` 复制到 microSD 卡**根目录**。
2. 格式：每行 `名称, 流媒体地址`（英文逗号分隔）。
3. 插入 Cardputer 右侧 SD 槽，进入 RADIO 即自动读取；没有 SD 卡则用内置电台。

## 操作速查

### 启动器
| 键 | 作用 |
|---|---|
| `;` `.` | 上下选择 |
| `enter` | 进入 |
| `` ` `` | （任意模式内）返回启动器 |

### SYNTH（合成器）
- **琴弦**：4 行 = 4 根弦（四度定弦），默认 A 小调五声锁定。
- `shift` 临时半音阶；底行点按 = 延音踏板；`-` `=` 八度；`\` 打拍子；`enter` 体感；`⌫` panic。
- `fn`+`q..p` 换音色；`fn`+`shift`+`q..p` 存音色；`fn`+`k/s` 调式/音阶；`fn`+`a/h/c` 琶音/和声/和弦；`fn`+`g` 和弦自动进行；`fn`+`d` 鼓组；`fn`+`1..8` 后 `[` `]` 调参数。
- `fn`+`k` **长按** = 麦克风听音识调（自动定调+BPM）；`tab` 打开 CREATE（随机/变异/撤销/SD 存取）。
- `alt` = SD 长循环器（录到 SD → 循环播放 → **叠加** → 停止）；`fn`+`alt` = 清空循环。
- `enter` = 体感（前后倾 = 双音色交叉淡化）。

### RADIO（收音机）
- `/` `,` 换台；`;` `.` 音量；`m` 静音；`l` 列表；`r` 重连；`b` 亮度。

### SETTINGS（设置）
- Theme 换主题；Brightness 亮度；WiFi connect 联网；Reset WiFi 清除网络。

## 常见问题（FAQ）

**Q：编译报 `'fonts' was not declared` 或类似？**
A：确认 M5GFX 库已安装；若仍报错，在报错文件顶部加一行 `using namespace m5gfx;`。

**Q：Flash 超限 / `Sketch too big`？**
A：分区方案没选对，必须选 **Huge APP (3MB No OTA / 1MB SPIFFS)**。

**Q：没声音？**
A：① 确认音量非 0；② 确认没按过 `m` 静音；③ 收音机模式需已连 WiFi；④ 检查串口日志是否有 `audio init failed`。

**Q：键盘多键一起按会死机吗？**
A：本工程用的是自研 TCA8418 读取器（每帧读 INT 电平 + 100ms I2C 兜底），多键和弦可靠，不会像原 M5Cardputer 读取器那样偶发锁死。

**Q：为什么没有「听歌自动识调」？**
A：该功能需要麦克风 ADC + 色度图分析，v1 暂未实现（见 README「已知限制」）。手动 `fn`+`k` / `fn`+`s` 可快速换调式。
