# Cardputer Studio · 客户手册（用户指南）

> 面向普通用户。不讲代码，只讲「这是什么、怎么玩、能干什么」。

---

## 一、这是什么

**Cardputer Studio** 是一台装在 **M5Stack Cardputer ADV** 里的「口袋音乐工作站」。一台巴掌大的小电脑，开机就是一个音乐系统，三个功能一键切换：

| 模式 | 一句话 |
|---|---|
| 🎹 **SYNTH** | 会唱歌的合成器：琴键即乐器，弹旋律、和弦、鼓、自己录循环 |
| 📻 **RADIO** | 网络收音机：连 WiFi 听全球电台 |
| ⚙️ **SETTINGS** | 换皮肤、调亮度、连 WiFi |

它把三个开源固件的功能合成了一个，界面统一、配色可选、按键即用。

---

## 二、有什么用（典型玩法）

- **随手弹一段旋律**：音阶锁定，怎么按都不跑调，零基础也能弹出好听的东西。
- **当合成器音色库**：18 种波形（钢琴、铃、弦乐、鼓、芯片、人声……），一键随机生成新音色。
- **当 DJ / 伴奏机**：左手锁和弦自动进行、右手 solo，像自带一支乐队。
- **听歌学调**：对着正在放的歌长按 `fn`+`k`，它用麦克风听出这首歌的调，自动帮你把琴调到对。
- **录音循环（Loop）**：弹一小段录进 SD 卡，循环播放、还能叠加，自己给自己伴奏。
- **听网络电台**：连上 WiFi，SD 卡里存好电台表就能听。

---

## 三、快速上手（30 秒）

1. 用 USB-C 开机，屏幕出现启动器 **CARD STUDIO**。
2. 按 `;` / `.` 上下选择，按 `enter` 进入（先选 **SYNTH**）。
3. 直接按键盘上任意字母/数字键 → 出声（默认 A 小调五声音阶，随便按都和谐）。
4. 按 `` ` ``（左上角反引号）随时返回启动器。

## 四、SYNTH 合成器怎么玩

### 4.1 键盘就是乐器
- **四行 = 四根「琴弦」**，像吉他一样按四度定弦。
- **音阶锁定**：默认 A 小调五声音阶，每个键都是音阶内的音，**怎么按都不跑调**。
- **滑音**：按住一键、再按同行另一键，音会滑过去（像无品吉他）。
- 按住 **`shift`**：临时变成半音阶（chromatic），松开回到音阶。

### 4.2 常用按键
| 按键 | 作用 |
|---|---|
| `-` / `=` | 八度 − / + |
| `ctrl` / `opt` | 音量 − / + |
| `\` | 打拍子定速度（BPM） |
| `enter` | 开关体感（倾斜换音色） |
| `⌫`（backspace） | 全部静音（panic） |
| 底行点按 | 锁一个「延音踏板」做伴奏 |

### 4.3 fn 组合键（按住 `fn` 再按）
| 按键 | 作用 |
|---|---|
| `fn` + `q..p` | 切换 10 个音色槽 |
| `fn` + `shift` + `q..p` | 把当前音色存进该槽 |
| `fn` + `k` | 换调式根音 |
| `fn` + `s` | 换音阶（大调/小调/布鲁斯……） |
| `fn` + `k` **长按 ~0.6s** | **听音识调**：麦克风听歌，自动定调 + 定 BPM |
| `fn` + `a` | 琶音器（↑→↓→↑↓→关） |
| `fn` + `h` | 和声（自动加三度） |
| `fn` + `c` | 和弦模式（一键一个三和弦） |
| `fn` + `g` | 底行模式切换：延音踏板 ↔ 和弦自动进行 |
| `fn` + `d` | 鼓组模式：底行变鼓垫 |
| `fn` + `1..8` 后 `[` `]` | 调参数（滑音/起音/衰减/波形/滤波……） |

### 4.4 一键出新音色（CREATE 菜单）
按 `tab` 打开菜单，`;` `.` 选择、`enter` 确认：
- **Randomize** 随机生成一个新音色（会先定「性格」再画，永远可弹）
- **Mutate** 在现有音色上变异
- **Undo** 撤销
- **Save SD / Load SD** 保存/加载到 SD 卡

### 4.5 循环器（Loop，`alt`）
- 点按 `alt`：四拍预备拍 → 开始录（把演奏实时写进 SD 卡，能录好几分钟）
- 再点：停止录制并循环播放
- 再点：**叠加一层**（边听边录，录满合拍自动并入）
- 再点：停止
- `fn` + `alt`：清空循环

## 五、体感（陀螺仪 / 倾斜）

- 按 `enter` 开启体感。
- **前后倾设备**：在当前音色和「上一个音色」之间**连续交叉淡化**——身体往后靠是当前音色，往前倾就「滑」到上一个音色，中间是两者的混合。
- 换音色、随机生成、变异、撤销时，会自动把「上一个音色」记下来，作为体感的目标。
- 再按 `enter` 关闭体感，回到当前音色。

## 六、RADIO 收音机

1. （首次）进 SETTINGS → **WiFi connect** 连网。
2. 把 `station_list.txt` 放到 SD 卡根目录（格式：`电台名, 流媒体地址`，每行一个）；没 SD 卡就听内置默认台。
3. 进 RADIO 后：

| 按键 | 作用 |
|---|---|
| `/` / `,` | 上/下一个电台 |
| `;` / `.` | 音量 + / − |
| `m` | 静音 |
| `l` | 电台列表（`;` `.` 选、`enter` 确认、`l` 关闭） |
| `r` | 重连 |
| `b` | 亮度 |

---

## 七、SETTINGS 设置

- **Theme**：6 套配色（Studio 暖黑 / Paper 灰 / OP-1 / Ocean / Forest / Mono）。
- **Brightness**：5 档亮度。
- **WiFi connect**：连接并记忆网络（最多 5 个）。
- **Reset WiFi**：清除已存网络。

## 九、常见问题

**Q：怎么按都不出声？**
A：确认在 SYNTH 模式；确认音量不是 0；确认没按过 `m` 静音（那是收音机的键）。

**Q：怎么不跑调？**
A：默认就锁定在 A 小调五声音阶，随便按都在调上；想换调用 `fn`+`k` / `fn`+`s`。

**Q：体感没反应？**
A：按 `enter` 才开启；开之前先换过一两次音色，它才知道「上一个音色」是谁。

**Q：循环器录了没声音？**
A：`alt` 点一下是「预备拍 + 开始录」，要再点一下才停止并循环；`fn`+`alt` 是清空。

**Q：收音机连不上？**
A：先在 SETTINGS 里连好 WiFi；确认 SD 卡的 `station_list.txt` 格式正确，或用内置默认台先试。

**Q：换主题/亮度会保存吗？**
A：会，重启后保留。
